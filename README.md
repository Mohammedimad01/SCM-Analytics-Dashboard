# SCM Analytics Dashboard

## Overview
This project is a Supply Chain Management Analytics Dashboard built using Power BI.

The dashboard provides insights into:
- Sales Performance
- Profitability
- Shipping Performance
- Regional Analysis
- Segment-wise Orders
- Customer Profitability

---

## Tools Used
- Power BI
- DAX Measures
- Microsoft Excel
- CSV Dataset

---

## Key Features
- KPI Cards for Sales, Profit, Orders, and Quantity
- Shipping Status Analysis
- Segment-wise Profit Comparison
- Region & State Profit Mapping
- Monthly Order Trend Analysis
- Top Profitable Customers
