## 🚀 Project Overview

This project is an interactive **Supply Chain Management Analytics Dashboard** built using **Power BI**, leveraging raw CSV and Excel datasets to generate actionable business insights.

The dashboard focuses on:

* Sales Analysis
* Profitability Tracking
* Shipping Performance
* Customer Insights
* Regional Performance
* Order Trends

## 🔍 Features

### ✅ Business Insights

* Consumer segment contributed the highest orders and profits.
* Standard Class shipping mode dominated total shipments.
* Interactive filtering by:

  * Month
  * Year
  * Region
  * Segment
  * State
